The plan

Six phases, each one playable

Every phase ends with a build you can open and play, not a pile of unfinished parts. If a phase runs long, we cut features from it, never ship it half-working.

Phase 2 in detail

Memory and relationships

Right now each person follows a fixed script. After this phase they bump into each other, remember it, and act differently the next day.

The one structural change: a day ledger

Today any moment can be computed straight from the seed, which is why catch-up is instant. Once relationships exist, tomorrow depends on what happened today, so that shortcut ends. The fix is to settle each day in order and keep a short record of it. Catch-up then replays missed days one by one, in small batches so a phone never freezes. Plans for the day stay deterministic, so the same seed still gives the same history.

Phase 2 is done when
  • After three in-game days, at least two pairs of citizens have clearly different relationships, and you can see why.
  • Leaving for 8 real hours returns a readable list of what happened, not just a number of days.
  • Two runs of the same seed produce identical histories (checked automatically).
  • The map holds a steady frame rate on a mid-range phone.
